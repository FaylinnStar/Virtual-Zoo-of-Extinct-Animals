# Virtual Zoo of Extinct Animals 
The VR Extinct Animal Zoo is an immersive educational virtual reality application developed using Unity, Blender, OpenXR, and XR Interaction Toolkit for Meta Quest 2. The project creates a virtual environment where users can explore extinct animals and learn about their characteristics, habitats, lifestyle, and extinction. The zoo features four animals: T-Rex, Woolly Mammoth, Megalodon, and Pteranodon, each placed in a suitable virtual habitat with terrain, vegetation, rocks, mountains, and water. Users can navigate through the zoo using VR teleportation and interact with educational information panels. Animal animations and spatial audio are included to make the experience more realistic and engaging. The project demonstrates how VR, 3D modelling, animation, and interactive design can be combined to create an engaging educational experience.
